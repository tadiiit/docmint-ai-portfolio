# DocMint AI

**AI-Powered Document Intelligence Platform**

DocMint AI helps users interact with their documents using AI. Users can upload PDF documents, search for relevant information, and ask questions in natural language.

## Features

- PDF upload and management
- Automatic text extraction
- Document chunking and storage
- Semantic search using embeddings
- AI-powered question answering
- Document processing status and error handling
- Structured information extraction

## Tech Stack

- **Frontend:** React
- **Backend:** Java, Spring Boot, Spring AI
- **Database:** MariaDB
- **Document Processing:** Apache Tika
- **AI:** Embeddings, semantic search, and Retrieval-Augmented Generation (RAG)
